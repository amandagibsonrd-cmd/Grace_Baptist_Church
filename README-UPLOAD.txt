GRACE BAPTIST CHURCH WEBSITE UPDATE
==================================

This package adds:

- Strong local SEO for Grace Baptist Church in Houma, Louisiana
- A 152-character Google meta description
- Canonical URL, Open Graph, Twitter card, and Church schema markup
- robots.txt and sitemap.xml
- The real daytime church photo in the hero
- A 1200 x 630 social-sharing thumbnail made from the real church photo
- A visible calendar flyer
- Searchable event cards that automatically hide past events
- An easy events.js file for future calendar changes

IMPORTANT: Keep the pastor photo already in GitHub named pastor.jpeg.
This package does not include or replace pastor.jpeg.

UPLOAD TO GITHUB
----------------

1. Extract this ZIP.
2. Open the Grace_Baptist_Church repository.
3. Click Add file, then Upload files.
4. Upload every file in this folder directly to the main repository page.
5. Allow GitHub to replace files with matching names.
6. Commit the changes.
7. Wait about one minute for GitHub Pages to deploy.
8. Refresh the website using Ctrl + F5.

You may leave old unused files such as hero-fix.css and site-config.js in the
repository. The new index.html does not load them.

CALENDAR UPDATES
----------------

Read EVENTS-UPDATE-GUIDE.txt for instructions. The short version:

- Replace events-calendar.jpg to change the printed flyer.
- Edit events.js to change the searchable event cards.
