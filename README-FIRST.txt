GRACE BAPTIST CHURCH — MODERN WEBSITE
=====================================

HOW TO PREVIEW
1. Double-click index.html to preview the site on your computer.
2. For a live preview, upload every file and the assets folder to GitHub Pages.

FILES YOU WILL UPDATE MOST OFTEN
- site-config.js — church name, pastor, address, service times, Facebook, and Google Calendar.
- assets/church-hero.webp — hero photo.
- assets/pastor.jpg — optional pastor photo. Use this exact filename.

GOOGLE CALENDAR
Paste the church's PUBLIC Google Calendar embed URL into googleCalendarEmbedUrl in site-config.js.
After that, leaders can update the calendar in Google Calendar and the website will update automatically.

GITHUB / GODADDY
Upload the CONTENTS of this folder, not the outer folder or ZIP. index.html must be at the root.
