HOW TO PREVIEW
1. Double-click index.html.
2. For GitHub Pages, upload every file directly to the repository main/root area.
3. Choose Replace when GitHub asks about index.html, styles.css, script.js, or site-config.js.
4. Commit changes, wait about one minute, then refresh the preview with Ctrl + F5.

IMPORTANT PHOTO FILE
Keep the existing pastor photo in GitHub named exactly: pastor.jpg
It should be beside index.html, not inside a folder.

FILES YOU WILL UPDATE MOST OFTEN
- site-config.js — church name, pastor, address, mission, service times, Facebook, and Google Calendar.
- church-hero.webp — the main church photo.
- pastor.jpg — pastor photo.

GOOGLE CALENDAR
Paste the church's PUBLIC Google Calendar embed URL into googleCalendarEmbedUrl in site-config.js.
After that, leaders can update the calendar in Google Calendar and the website will update automatically.
