UPDATING GITHUB
1. Extract this ZIP file.
2. Upload every file directly to the main GitHub repository page.
3. Choose to replace files with the same names.
4. Keep your existing pastor.jpg file in the repository.
5. Commit the changes.
6. Wait one or two minutes, then refresh the website with Ctrl + F5.

IMPORTANT FILES
- index.html: website page content
- styles.css: website design
- script.js: menu and automatic website functions
- site-config.js: church name, address, pastor, mission, service times, and Facebook URL
- grace-logo-full.webp: full church logo used in the page
- grace-logo-mark.webp: compact logo used in the header and footer
- favicon.png: browser tab icon
- church-hero.webp: church photograph used at the top
